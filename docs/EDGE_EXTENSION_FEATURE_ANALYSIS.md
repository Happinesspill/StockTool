# EdgeExtensions 插件功能分析

分析对象：`EdgeExtensions/2.6.1.0_0`

插件名称：股票基金助手 - xStock

分析依据：

- `manifest.json`：插件入口、权限、后台服务、快捷键、数据域名。
- `_locales/zh_CN/messages.json`：插件名称和简介。
- `_locales/zh_CN/components.json`、`_locales/zh_CN/pages.json`：页面、弹窗、菜单、设置项和业务文案。
- `js/service_worker.js`、`js/bg_helper.js`：后台轮询、通知、角标和部分行情/预警逻辑。
- `assets/app.js`、`assets/app2.js`、`assets/Settings.js`：压缩后的 Vue 应用代码，仅做静态功能线索分析。

说明：插件前端代码已压缩/打包，本文不复刻其源码，只整理可参考的产品功能和本地 WPF 实现建议。

## 1. 总体定位

xStock 是一个浏览器股票/基金助手，核心能力包括：

- 自选股分组管理。
- 实时行情列表。
- 股票/基金搜索。
- 股票详情、K 线、资讯、档案、基金数据。
- 持仓成本与盈亏统计。
- 价格/涨跌幅/换手率/量比预警。
- 市场行情、板块、成分股。
- 皮肤、显示密度、多语言、窗口尺寸等个性化设置。
- 登录、云同步、反馈、版本检查。
- 高级交易、条件单、回测、题材监控等需要账户或后端能力的功能。

## 6. 预警提醒

预警条件：

- 股价高于目标价。
- 股价低于目标价。
- 日涨幅达到。
- 日跌幅达到。
- 换手率高于。
- 量比高于。
- 高位回落。
- 低位反弹。

提醒频率：

- 单次提醒。
- 每日一次。
- 每 5 分钟。

后台实现线索：

- `service_worker.js` 创建 `STOCK_ALERT_ALARM`。
- 轮询间隔为 `10/60` 分钟，即约 10 秒。
- 存储键包括：
  - `bg_monitor_list`
  - `notification_settings`
  - `bg_notification_history`
  - `bg_monitor_state`
  - `bg_consumed_once_items`
- 触发后使用浏览器通知。
- 单次提醒触发后会清空对应条件，若无剩余条件则移除该监控项。

本地实现建议：

| 功能 | 优先级 | 难度 |
|---|---:|---:|
| 价格上/下限提醒 | 高 | 中 |
| 涨跌幅提醒 | 高 | 中 |
| Windows Toast 或托盘气泡通知 | 高 | 中 |
| 每日一次/单次/间隔提醒 | 中 | 中 |
| 高位回落/低位反弹 | 中 | 中高 |
| 换手率/量比提醒 | 中 | 中 |

## 18. 结论

最值得从插件迁移到本地 StockTool 的功能是：

1. 持仓盈亏展示与汇总。
2. 价格/涨跌幅预警。
3. 列表列增强和多列排序。
4. 股票详情 K 线周期扩展。
5. 搜索和分组体验增强。

交易、条件单、云同步和复杂策略回测属于高复杂度、高外部依赖功能，建议后置。
